01 / About

我喜欢把「这个能不能做出来？」变成可以打开、使用和继续改进的项目。

兴趣主要在 全栈开发、人工智能、推荐系统与数据分析。比起只停留在技术概念上，我更在意如何把它们用到具体问题里：让信息更容易找到，让数据更容易理解，让应用更好用。

I explore full-stack development, AI, and data-driven applications — turning curiosity into practical projects, one iteration at a time.
